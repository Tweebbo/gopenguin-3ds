# Release notes

## 1.3.5

- Adds the original special outfit actions, including the pizza outfit and mining gear.
- Adds Cave Mine digging with 10 coins per normal reward and a rare 100-coin reward. Move after five rewards to keep digging.
- Makes quick Pizzatron topping taps and sauce contact register more reliably, with less repeated graphics preparation.
- Makes small catalogue Buy buttons easier to tap. Catalogue cameras ignore Circle Pad drift and retain their position while tapping, dragging and zooming.
- Recovers a saved penguin from valid SD backup files when the main identity file is damaged. If recovery is not possible, the game asks for a restore instead of creating another penguin automatically.
- Includes the memory allocator correction from libctru 2.7.1.
- Offers smaller CIA and 3DSX downloads from 1.3.4, with complete packages as fallback.

Install the optional update from Help > Account > Updates. Keep an SD backup and your account recovery code. Versions 1.3.1 and 1.3.2 require a fresh CIA or 3DSX installation.

PC also receives the outfit actions, mining and faster repeat room visits. See the [full changelog](https://gopenguin.lol/changelog/).

Build, package, host, isolated multiplayer and Old/New 3DS emulator checks passed. Physical-console installation and touch acceptance remain unverified.


## 1.3.4

- Restores bottom-screen icons and the Halloween rooms, map, poster and music.
- Improves clothing loading and rendering, with a cache that adapts to available memory.
- Adds Help > Graphics > Hide other penguins, off by default. Chat and the player list remain available.
- Registers chat letters on touch-down and caches unchanged input layout.
- Offers incremental downloads from 1.3.3, 1.3.0, 1.2.5 and 1.2.3 for CIA and 3DSX.

See the [1.3.4 release details](RELEASE-1.3.4.md) for controls, update instructions and test limitations.

## 1.3.3

- Fixes GoPenguin stopping at startup on versions 1.3.1 and 1.3.2.
- Restores Agent Mission 1, the mission interface and the snowball artwork.
- Turn your seated penguin with the C-Stick, or by holding B and using the Circle Pad, D-Pad or map.

If you have 1.3.1 or 1.3.2, the game cannot update itself. Install the latest CIA or 3DSX again. Your penguin is kept.

Older releases are listed on [GitHub Releases](https://github.com/Tweebbo/gopenguin-3ds/releases). The [player changelog](https://gopenguin.lol/changelog/) covers every platform.
